# Third-party data notice

MotionSense uses the **Human Activity Recognition Using Smartphones** dataset
from the UCI Machine Learning Repository, DOI: [10.24432/C54S4K](https://doi.org/10.24432/C54S4K).
The dataset is licensed under the Creative Commons Attribution 4.0 International
license (CC BY 4.0). Please attribute Reyes-Ortiz, Anguita, Ghio, Oneto, and
Parra, *Human Activity Recognition Using Smartphones*, UCI Machine Learning
Repository (2013).

The source dataset contains features derived from accelerometer and gyroscope
measurements, including total-acceleration signal axes. This UCI dataset is not
confirmed to be identical to the missing book file `data/samsung_data.txt`.
